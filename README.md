# Smartsort Solutions

1. Install dependencies:
   `npm install`

2. Run locally:
   `npm run dev`

## Newsletter setup

The newsletter form submits to a Formspree endpoint. The endpoint URL is not generated by this app; create it in your Formspree account first:

1. Sign in at [formspree.io](https://formspree.io/) and create a new form.
2. Copy the form endpoint. It will look like `https://formspree.io/f/your-form-id`.
3. In Vercel, open the project, then go to **Settings -> Environment Variables**.
4. Add `VITE_FORMSPREE_ENDPOINT` with the copied URL. Enable it for **Production** (and Preview if needed).
5. Redeploy the latest commit. Vite embeds `VITE_*` values during the build, so changing the variable alone does not update an already-built deployment.

You can use `VITE_NEWSLETTER_ENDPOINT` instead, if you are using another service that accepts the same form POST. Do not commit the real endpoint to `.env.example`; set it in Vercel and in a local, ignored `.env.local` file when testing locally:

```env
VITE_FORMSPREE_ENDPOINT=https://formspree.io/f/your-form-id
```
